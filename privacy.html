Privacy Policy

Effective November 6, 2026

This policy describes the existing informational Story Pipeline website and the current desktop workflow. It does not claim that TikTok sign-in or publishing is currently active.

1. Operator and contact

Story Pipeline is maintained by its project operator. Requests about this policy can be made using the GitHub project issue form. Do not include confidential data in public issues.

2. Website data

This static website has no account sign-in, tracking pixels, visitor upload forms or custom analytics. GitHub Pages hosts the website and may process technical requests according to GitHub's privacy statement.

3. Local desktop data

The desktop workflow can store video titles, source URLs, durations, engagement statistics, processing history, media and output files in a local workspace and database managed by the operator. The operator controls any additional backups or export locations.

4. Planned TikTok authorization

If account linking is developed and enabled, users will be asked to authorize requested TikTok permissions. An approved implementation may need account identifiers, display names, OAuth tokens and publishing metadata. That feature is not currently active. This policy will be updated before public release with accurate storage, security, retention, deletion and scope details.

5. Sharing with third parties

Necessary API requests can be sent to relevant external platforms when the operator chooses to use those functions. This website does not sell personal data. We cannot control independent privacy practices of GitHub, YouTube or TikTok.

6. Retention and deletion

Locally stored project files can be deleted by the operator. Other backups and external copies must be handled separately. Any future TikTok connection will support the platform's revocation process and document account-data deletion procedures before public launch.

7. Security

Keep credentials and OAuth tokens private. Do not add secrets to a public source repository or submit them through this website.

8. Children and platform eligibility

Any authentication and publishing functions must comply with the relevant platform age and eligibility requirements. The project does not provide a method to bypass those restrictions.

9. Changes

Changes to data-handling practices will be reflected in an updated policy at this page.

10. Contact

See the project contact page for policy questions. Do not share sensitive information in public issues.
